# Python Programming for Data Analytics

This repository contains my Python programming assignments focused on **NumPy and Pandas** for Data Analytics. The project covers fundamental concepts of numerical computing, data manipulation, data cleaning, and basic data analysis.

## 📌 Project Overview

The objective of this project is to practice Python libraries commonly used in **Data Analytics** and develop practical skills in working with structured datasets.

### Technologies Used

- Python
- NumPy
- Pandas
- CSV

## 📂 Tasks Covered

### Task 1: NumPy Basics
- Import NumPy
- Create NumPy arrays
- Display arrays
- Check array shape, size, and data type
- Create one-dimensional and two-dimensional arrays

### Task 2: NumPy Indexing, Slicing & Reshaping
- Access elements using indexing
- Perform array slicing
- Create two-dimensional arrays
- Access rows and columns
- Reshape arrays into different dimensions

### Task 3: NumPy Mathematical & Statistical Operations
Mathematical operations:
- Addition
- Subtraction
- Multiplication
- Division

Statistical operations:
- Mean
- Median
- Minimum
- Maximum
- Standard Deviation
- Sum

### Task 4: Pandas Series & DataFrame
- Create a Pandas Series
- Create a DataFrame
- Display DataFrame
- Display column names and index
- Add a new column
- Display the updated DataFrame

### Task 5: Reading & Inspecting Data
- Read CSV files using Pandas
- Display first 5 rows using `head()`
- Display last 5 rows using `tail()`
- Check rows and columns
- Display column names
- Check data types using `dtypes`
- Use `info()` and `describe()`

### Task 6: Selecting, Filtering & Sorting Data
- Select specific columns
- Select specific rows
- Filter records using conditions
- Apply multiple filtering conditions
- Sort data in ascending order
- Sort data in descending order

### Task 7: Handling Missing Values
- Identify missing values using `isnull()` and `isna()`
- Count missing values
- Remove rows containing missing values
- Fill missing values using appropriate methods
- Compare datasets before and after handling missing data

### Task 8: Merge, Concatenate, GroupBy & Pivot Table
- Merge DataFrames using a common column
- Concatenate multiple DataFrames
- Group data using `groupby()`
- Calculate sum, mean, count, minimum, and maximum
- Create Pandas Pivot Tables

### Task 9: Exporting Data
- Process a DataFrame
- Export the final DataFrame to CSV
- Verify the exported CSV file
- Save processed data for submission

### Task 10: Mini Data Analysis Project
A basic **Student Performance Analysis** project using NumPy and Pandas.

The project includes:
- Dataset creation
- Data inspection
- Statistical analysis
- Student filtering
- Study-hours analysis

- Performance categorization
